# 遮挡片段的带纹理透明外壳

已接入时间线的 RenderEntry 渲染路径，不改变片段透明度设置和前序片段的遮挡判定。

- 已落位、快照为单位变换、可见性处于半透明 ghost 状态的方块参与外壳渲染；尚在运动或淡入/淡出的方块继续使用原动画渲染。
- 使用原生世界模型剖分，保留资源包纹理、随机纹理方向、群系染色、AO 和光照。由相邻方块剔除内部面，不使用容器的长方体包围盒替代真实形状。
- 同一平面上纹理、UV 旋转/镜像、颜色、光照、透明度一致的完整方块面进行贪婪矩形合并；光照渐变、草侧面叠层、植物、台阶等保留原生四边形。
- 纹理通过专用地形着色器在原方块图集中按每格重复，保留纹理尺度。覆盖/法线顶点属性承载图集像素起点和纹理尺寸，颜色和光照属性不变。非二次幂纹理尺寸和过大的图集偏移退回原生四边形。
- 透明外壳在动画模型之后提交，不写深度，仍参与深度测试和透明四边形排序，避免透明外壳挡住后方动画。
- 旧纯色覆盖路径不再绘制已注册的时间线条目；没有时间线条目的 ghost 状态也走带纹理的渲染器。
- 使用稀疏平面网格，不扫描两个远处分散方块之间的空体积。每帧重新采样原生光照与模型，避免资源重载、编辑方块或日夜变化时缓存过期；暂未引入 GPU 网格缓存。

## 验证

编译通过，148 项相关回归测试全部通过（22 个测试类，零失败、零跳过），git diff --check 通过；测试覆盖规则墙面合并、孔洞、不同材质/染色/光照/透明度的隔离、远处分散岛屿、随机形状的覆盖守恒、以及透明管线的顶点格式和深度写入。

未启动游戏验证 GPU 着色器和实际画面，也未打包 JAR。建议手动检查：

1. 前序片段使用普通石头/泥土墙，后序片段在其后动画：前墙应保留每格纹理尺度并可透视后方动画。
2. 带孔洞和阶梯形外轮廓的容器：孔洞保持，不出现包围盒或内部方格面。
3. 草地、植物、台阶混合容器：保留原形状和透明纹理空隙，不变成透明方盒。
4. 修改透明度，拖动播放头、停止/重播：外壳随当前状态更新；取消遮挡后恢复世界方块。
5. 夜晚、不同群系、F3+T 资源重载与非默认资源包：纹理方向、染色和光照应随原生数据变化。
6. 如使用第三方光影/渲染器，需要单独验证自定义地形着色器与其兼容性；未有运行证据前不声明兼容。
