# 演员动画修改记录

本轮在演员编辑目标、播放时钟、通道操作和放置流程的改造上补齐交互边界。

- 骨骼时间轴选中关键帧时，通过可见所属片段解析 Spawn 内嵌动画；拖动期间也接受这种归属，避免错误取消。
- 路径距离驱动的动画允许编辑当前实际步态相位的姿态值，但禁止通过场景时间轴拖动或数值输入重定时。底层移动服务同样拒绝该操作。需要调整键时间时使用独立动画预览。
- 快速姿态自动应用的提示明确区分快速姿态、骨骼动画拖动和数值编辑的提交方式。
- 清理手工修正旁路界面的无用局部变量；旁路状态继续由 Spawn 保存，不修改原有混合权重。

已有改造包含：统一编辑目标和距离时钟、完整关节镜像及所选键镜像、保留当前 TRS 创建 Transform、演员放置身份及撤销、Root 通道粘贴合并、事件时钟和持久化、预设绑定校验、保存姿态的撤销及重新加载。旧事件默认保留片段进度语义，动画源进度需要显式选择。

未实现预设包分享。Minecraft 客户端内的实际渲染和鼠标交互仍需人工验收，自动回归不能替代这部分检查。
