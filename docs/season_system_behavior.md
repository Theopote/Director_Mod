# 季节轨道行为

季节参数以时间线为准；首尾关键帧外保持端点参数。线性、平滑和 Catmull-Rom 分别控制匀速、缓入缓出和使用相邻关键帧参数切线的曲线过渡。覆盖率限制在 0–1，颜色偏移限制在 -0.99–3，非有限参数会被归零。

属性编辑可以预览关键帧时间，模型保存通知不会覆盖预览；播放、拖动时间线或切换激活轨道会结束该预览。禁用、删除最后一个关键帧、解绑模型、关闭 Director 和断开连接都会清理效果。再次绑定同一时间线会重新构建采样器。

雪、冰只修改客户端视觉状态，不修改服务器存档。扫描和方块写入均在客户端线程分批执行，不再使用结冰后台线程或独立游戏 tick 的逐层动画。雪层按当前时间线目标直接设置，层数取整及位置噪声仍会产生离散层数变化；这些是 Minecraft 雪层方块的限制。

扫描围绕实际镜头，只处理已加载区块。雪、冰扫描范围为镜头所在区块中心附近半径 128 方块，约 17×17 个区块。所有位置保持逐列采样，不再使用远处规则隔格采样。镜头跨区块或加载集合变化时，保留已扫描的重叠范围及其效果，只扫描新增、重新加载或尚未完成的位置；只恢复离开范围的旧效果。雪线扫描使用当前维度的实际高度。未加载区域和超出范围的空间不承诺季节覆盖。

每个积雪位置及冻结水面保存原始状态，恢复前确认当前方块仍属于本系统的视觉修改，避免覆盖服务器或用户后来修改的方块。世界切换会丢弃旧世界的扫描缓存；关闭不会永久禁用任何单例线程池。

地形构建对单个区块固定季节颜色快照。颜色刷新节流会保留最后一次请求，并刷新所有驻留区块。视频抓帧等待几何扫描、雪冰写入和可见地形构建/上传完成；相同时间点与相同加载地形下，积雪厚度和结冰覆盖可重复。该保证不涵盖原版随机事件、第三方光影及加载地形差异。

季节湿度目前作为持久化和插值参数保留，尚未驱动独立天气概率或雾密度系统。

覆盖场使用世界 X/Z 坐标锚定的多尺度连续噪声，雪、冰使用不同种子和尺度；同一位置的形态不会随镜头或扫描顺序改变。噪声分布经近似累积分布映射，使高覆盖度仍保留自然孔隙（雪最大有效覆盖度 0.97，冰 0.92）。参数表示近似面积比例，不保证每个小区域的精确占比。雪层使用连续雪堆高度噪声，斑块边缘从单层逐渐加厚；雪线附近约 24 格高度范围内平滑改变覆盖率。
