# 演员 UI 设计建议吸收记录

日期：2026-10-26。对照用户提供的《演员编辑器 UI 设计》与当前代码，将本轮范围限定为动作浏览、信息层次和可执行反馈。

## 本轮已实现

- 预设绑定入口由扁平下拉改为可展开的动作浏览区：名称/ID/骨架搜索，项目/内置来源筛选，表演/循环步态/静态姿态用途筛选，固定高度滚动列表。当前绑定始终显示；无预设项不受搜索影响，便于随时清除。
- 项目动画资产库增加搜索、用途和兼容性筛选及独立滚动区；选择在筛选范围外的资产时明确显示当前资产，筛选不改变引用。没有选中演员时可浏览项目所有资产。
- 共享只读 ActorAnimationCatalog 只读取元信息，不在列表绘制时逐个采样资产。项目资产 ID 优先于同名内置动画，即使项目资产不兼容也不把同 ID 内置动作作为可绑定项，避免显示与运行时实际取值不同。
- 常用权重、部位快捷范围保留直接操作；高级混合、淡入淡出、TRS 通道、逐骨骼自定义掩码、新资产设置与资产 ID 使用展开项。折叠不会重置现有值。
- 空白资产与被掩码排除的资产分别反馈；后者提供当前片段“恢复全部部位与通道”动作，复用属性草稿与撤销，不改共享资产。

## 需要修正或后续设计的建议

- ActorSelectorPanel 是备用入口，不能据此认定主 Actors 面板只有简易列表。ActorTimelineAnimationPanel 仍无生产调用，不能用类的存在认定当前重复显示两套骨骼面板。
- 部位分段按钮、真实时钟冲突提示和当前片段上半身修复按钮已经存在，本轮保留。
- 独立 ActorStudio、悬停试播、层栈与 HUD、模板库、时间线层带尚未实现。它们需要独立的选择/草稿生命周期和实际数据契约，不能仅靠搬移渲染调用完成。
- 不默认对全部骨骼补满静止首尾关键帧，保留稀疏通道透传；不根据一个全局 tier 默认隐藏用户制作的步态资产；不把“影响腿部且本地时钟”表述为必然滑步。
- 当前预设影响反馈不能直接提供四层统一“贡献百分比”，尤其不能从预设权重推算脚底 IK 百分比。悬停试播也不能用修改模型再撤销代替独立预览快照。
