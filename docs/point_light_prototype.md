# 灯光类型、轨道与参数动画

灯光保存在当前世界的 Director 时间线项目中，不修改世界方块或服务器光照。支持点光源、折线光源和双面矩形面光源。

## 放置与编辑

从“窗口 → 灯光”打开面板：

- 点光源：点击“放置点光源”，在场景表面右键放置。
- 线光源：点击“绘制线光源”，右键依次添加锚点，左键完成（2–128 个锚点），Esc 取消尚未完成的绘制。完成后左键点击锚点，用平移 Gizmo 调整；从列表选中则移动整条折线。
- 面光源：点击“放置面光源”，右键放置，初始朝向贴合所点表面。左键点击中心标记或从列表选择，用 Gizmo 移动；属性面板调整宽、高、水平朝向和倾角。

三种灯光均支持位置、亮度（0–15）、衰减范围（1–32 格）、衰减曲线（0.25–4）及启用状态。面光源宽高为 0.1–64 格。参数修改立即预览，松开控件或结束输入后自动提交，无“结束编辑”按钮。连续参数调整和每次 Gizmo 拖拽各产生一条撤销记录。点击空白处退出选择；Esc 取消放置或未完成的 Gizmo 拖拽。

## 轨道与片段

每次完成放置都会自动创建一条 LIGHT 灯光轨道和一个绑定该灯光的片段。片段从当前播放头开始，结束于项目末尾，并确保至少 5 秒。

- 灯光只在片段的 `[开始时间, 结束时间)` 内生效；间隙、删除片段或禁用轨道时不发光。
- 拖动片段改变出现时段，参数关键帧跟随平移；拖动边缘或在片段属性中修改开始/结束时间改变持续时间。
- 支持复制、粘贴和跨灯光轨道移动。复制片段仍引用同一个场景灯光，关键帧独立，适合多段出现。
- 轨道的可见、静音和独奏开关参与灯光采样，锁定禁止片段编辑。独奏在灯光轨道之间生效。
- 同一灯光的多个片段重叠时，开始时间较晚的片段优先；开始时间相同则按轨道顺序优先。
- 删除场景灯光会同时移除它的片段，撤销恢复两者。

## 参数关键帧

选中片段，在属性面板点击“在播放头添加参数关键帧”，或使用片段右键菜单；双击片段可在点击时间添加/删除关键帧。

关键帧保存一份完整灯光参数。选中关键帧后，属性面板编辑该关键帧的亮度、范围、衰减、位置及面光源尺寸/朝向；Gizmo 编辑其位置或线光源锚点。参数无需确认按钮。可拖动关键帧改变时间，并选择线性、平滑或阶梯插值。插值模式由区间左侧关键帧决定，首帧之前和末帧之后保持最近的参数值。

没有关键帧的片段使用场景基础参数。有关键帧后，动画参数来自关键帧；修改基础值不会覆盖已有关键帧。场景灯光的“启用”是总开关，关键帧也可设启用状态。亮度 0 可实现淡入淡出。线光源锚点数量一致时支持锚点位置插值；面光源水平朝向按最短角度路径插值。

裁剪会在新边界补入采样值并移除区间外关键帧；撤销恢复原始关键帧。线性和阶梯曲线保持对应边界行为，平滑曲线会在剩余关键帧之间重新插值。

## 光照行为与兼容

距离衰减为 `亮度 × (1 − 距离 / 范围)^衰减曲线`：点光源使用到点的距离，线光源使用到最近折线段的距离，面光源使用到矩形表面的距离。多个光源取最大贡献，保留更亮的原版方块光及天空光。

采用原版光照贴图，暂不支持 RGB、遮挡或投射阴影，光照会穿墙。面光源为双面发光。强天空光可能掩盖变化，建议在夜间暗室检查。

区块网格会刷新新旧影响范围；演员及动画容器按显示位置采样。播放、拖动播放头和视频导出使用相同时间线采样。导出隐藏编辑标记，并等待光照变化后的区块网格刷新（包括灯光关闭），仍受已有抓帧超时限制。

旧点光源项目自动迁移到覆盖项目时段的灯光片段；新项目保存灯光类型、几何和参数关键帧。没有灯光的旧项目不会新增灯光。

## 视觉验收

1. 在夜间暗室分别放置三种灯光，检查折线每一段及矩形整面发光。
2. 修改参数、移动锚点、调整矩形朝向；撤销、重做并重开项目。
3. 将片段设为 2–5 秒，检查 2 秒前及 5 秒后关闭。
4. 添加亮度 0 和 15 的关键帧，检查渐亮、阶梯切换、关键帧拖动及片段平移。
5. 导出短序列，检查出现/熄灭帧与编辑标记隐藏。

自动测试覆盖几何距离、边界、时段、插值、存档迁移、撤销重做。游戏内视觉效果和实际导出仍需按以上步骤验收。
