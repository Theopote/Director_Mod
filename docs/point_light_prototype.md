# 点光源原型

本阶段实现常驻场景点光源，先验证 Director 在原版渲染中的局部照明接入。灯光保存在当前世界的时间线项目中，不修改世界方块，也不改变服务器光照或生物生成规则。

## 使用

1. 从“窗口 → 灯光”打开面板，点击“放置点光源”。
2. 在场景表面右键放置。光源离表面约 0.35 格，随后自动选中。
3. 左键点击灯光标记，或在灯光列表中选择。用平移 Gizmo 移动；黄色圆圈表示衰减范围。
4. 在属性面板编辑位置、亮度（0–15）、范围（1–32 格）、衰减曲线（0.25–4）和启用状态，调整立即预览，松开控件或结束输入后自动保存。一次连续参数调整和每次 Gizmo 拖拽分别产生一条撤销记录。
5. 点击场景空白处或切换选中对象退出灯光选择；Esc 仍可取消放置或尚未完成的拖拽。删除、移动和参数调整支持时间线的撤销/重做。

关闭灯光面板或切换工具会退出灯光编辑。已保存的光源仍属于场景。关闭 Director 界面的渲染清理和重新采样遵循现有项目生命周期。

## 光照行为

- 距离衰减：`亮度 × (1 − 距离 / 范围)^衰减曲线`，范围外贡献为 0。
- 多个光源取最大贡献，保留更亮的原版方块光照及原版天空光照。
- 采用原版光照贴图，所以颜色受原版贴图和现有环境设置影响，暂不提供 RGB 参数。
- 没有遮挡计算、投射阴影和方向性，灯光会穿墙。白天的强天空光会掩盖变化，建议在夜间或暗室验收。
- 世界方块通过区块网格采样；移动/关闭/删除光源会刷新旧、新影响范围。演员通过实体渲染采样，动画容器按显示位置采样。
- 导出采样包含灯光；编辑标记和范围圆圈在导出时隐藏。有启用灯光时，抓帧等待可见区块网格完成刷新；仍受原有 10 秒抓帧超时限制。
- 项目加载兼容没有 `pointLights` 的旧文件。场景重置会清空灯光。

## 验收步骤

1. 在夜间暗室中放置点光源，对比附近墙面和地面；调小范围后确认远处恢复暗度。
2. 移动、禁用、删除光源，确认旧位置没有残留亮斑；逐次撤销、重做。
3. 让演员与动画容器经过光源，检查光照随显示位置变化。
4. 保存并重新打开项目，检查 ID、位置和参数；切换到另一存档，检查没有灯光串档。
5. 导出短 PNG 序列，检查首帧亮度及标记隐藏。

灯光专项自动测试覆盖衰减、天空光保留、影响范围、旧文件兼容、参数校验、模型重置、撤销重做和动画方块采样位置。进游戏的视觉验收和实际视频导出仍需完成；自动测试不能替代这部分。

## 后续范围

LIGHT 轨道、灯光片段、关键帧动画、线光源、面光源，以及 RGB/阴影渲染后端属于后续阶段，本原型未实现。
