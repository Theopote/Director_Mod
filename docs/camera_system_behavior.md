# 摄像机运行规则与验收

## 已实现的行为

- 镜头片段使用 `[开始时间, 结束时间)`。相邻片段在切点由后一个片段接管；零时长片段不接管。
- 阶梯位置与阶梯旋转在下一关键帧的精确时间切换。片段终点仍可单独采样用于绘制路径、解析后续片段入口。
- 推拉、升降、环绕片段按时间线递归解析前序片段的入口和终点；有关键帧锚定的路径，顺序播放、跳转、倒序采样和重复采样应得到相同结果。
- 没有前序镜头和关键帧锚点的相对路径，使用采样会话首次取得的视角作为入口，之后保持该入口；不同初始视角仍可产生不同路径。这符合“自动对齐当前视角”的语义。
- 仅在取得有效镜头样本时接管。空档、禁用或没有关键帧的自定义片段释放接管，渲染玩家当前视角。
- 静态预览切换轨道、项目或发生结构变更时，不沿用旧镜头缓存。
- 属性控件修改位置、旋转和 FOV 时直接预览当前值；松开拖拽后刷新关键帧排序及路径缓存。仅展示属性不会反复夺取玩家控制权，玩家输入可退出预览。
- 播放、拖动播放头时锁定玩家移动；退出静态预览后恢复自由移动。
- 玩家视角导出明确释放时间线接管；选择轨道导出时按帧采样，空档使用玩家视角。导出期间不运行普通播放/属性预览采样。
- 导出完成、取消或失败后，在客户端线程恢复原激活摄像机轨道、播放头、静态预览及播放状态；项目已切换则不恢复旧项目。
- 模型解绑和界面关闭清理接管状态及路径入口缓存。

## 当前限制

原版渲染接入位置、旋转（含翻滚）和 FOV。自定义近远裁剪面及景深尚未接入渲染；属性面板显示说明并禁用对应控件，已有存档值保留。本次没有实现景深后处理。

## 游戏内验收

1. 串联推拉、升降和自定义镜头，分别顺序播放、直接跳转及来回拖动，比较相同时刻的位置、朝向。
2. 使用相邻片段及阶梯关键帧，在切点截图，确认切换时刻正确；片段间留空并禁用片段，检查玩家视角恢复。
3. 拖拽位置、旋转及 FOV 后松开，检查预览、路径、重新播放结果；移动鼠标退出预览，确认属性面板不会重新抢回控制。
4. 静态预览时切换 A/B 轨道，检查画面同步；播放时关闭再打开界面或切换项目，检查无接管残留。
5. 分别导出玩家视角、另一摄像机轨道和包含空档的序列；完成或取消后检查原轨道、播放头和播放状态恢复。

自动测试覆盖采样及状态切换；实际画面、属性交互、输入锁定和导出视频仍需游戏内验收。
