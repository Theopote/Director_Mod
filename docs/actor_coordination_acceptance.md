# 动作协调验收

入口：在时间线上选中演员的 Spawn 片段，查看属性顶部“动作协调 · 当前播放头”。

1. 片段内有路径：基础区域显示采样动作、速度、路径名称、区间长度和循环方式；“查看路径片段”应选中原路径，不新增片段。
2. 仅有预设：预设行报告实际通道，手工行未启用。启用快速头部姿态后，它应覆盖预设头部；再加手工头部旋转，应由手工层覆盖快速姿态。
3. 预设权重为零、通道筛空、骨架不匹配：分别显示权重为零、无声明通道、图层被拒绝；不显示虚构的生效部位。
4. 玩家沿路径落脚：脚底行显示本帧是否修改通道，不显示推算的 IK 百分比。原生非玩家模型没有可编辑骨骼求解快照时明确显示暂无快照。
5. 注视丢失目标：显示未生效原因，骨骼来源保留基础动画；“查看注视片段”只导航到已有生效区间内的注视片段。
6. 播放头移出检查片段、静音、重叠片段切换或切换工程：不得把旧快照或其他片段的结果显示在当前片段名下。
7. 从协调区域查看设置：先结束当前属性草稿；查看预设应展开并滚动到设置，查看手工/快速姿态应进入对应编辑目标，不创建动画或关键帧。
8. 自制循环步态设为 LOCOMOTION：沿路径时改变预设速度不应改变距离相位；历史目标查询和实时采样采用相同的解析时钟。
