# ChronoBlocks 多屏渲染技术分析

## 需求概述

将ChronoBlocks的ImGUI活动面板（可拖动面板）渲染到Minecraft窗口外，支持双屏或多屏使用场景。

## 技术方案

### 方案一：使用ImGUI多视口（Multi-Viewport）功能（推荐）

**优点：**
- ImGUI 1.86.11已原生支持多视口功能
- 实现相对简单，只需启用相应配置标志
- 自动处理窗口管理、输入事件分发
- 支持将面板拖拽到独立窗口
- 与现有代码兼容性好

**实现步骤：**

1. **启用多视口功能**
   - 在`ImGuiRenderer.init()`中添加`ImGuiConfigFlags.ViewportsEnable`标志
   - 配置ImGuiIO以支持多视口

2. **配置平台后端**
   - `ImGuiImplGlfw`需要支持多视口
   - 确保GLFW窗口创建和销毁正确管理

3. **面板窗口标志**
   - 为需要外部显示的面板添加`ImGuiWindowFlags.ViewportMenuBar`等标志
   - 允许面板创建独立视口

**技术细节：**
- 多视口功能允许ImGUI窗口创建独立的原生窗口
- 当窗口被拖出主窗口边界时，自动创建新视口
- 每个视口可以位于不同的显示器上

### 方案二：创建独立的GLFW窗口

**优点：**
- 完全控制窗口创建和管理
- 可以自定义窗口属性

**缺点：**
- 实现复杂，需要手动管理多个窗口
- 需要处理输入事件分发
- 需要同步多个OpenGL上下文
- 与Minecraft的渲染系统可能冲突

### 方案三：使用ImGUI的Platform窗口抽象

**说明：**
- ImGUI提供了平台窗口抽象层
- 需要实现自定义的Platform窗口后端
- 适合需要深度定制的场景

## 推荐实现：方案一（多视口）✅ 已实现

### 代码修改点

1. **ImGuiRenderer.java** ✅
   ```java
   // 在init()方法中启用多视口
   io.setConfigFlags(ImGuiConfigFlags.NavEnableKeyboard 
       | ImGuiConfigFlags.DockingEnable 
       | ImGuiConfigFlags.ViewportsEnable);  // 已添加
   ```

2. **渲染循环** ✅
   - 在`renderPendingDrawData()`中添加了多视口更新和渲染：
     ```java
     if ((ImGui.getIO().getConfigFlags() & ImGuiConfigFlags.ViewportsEnable) != 0) {
         ImGui.updatePlatformWindows();
         ImGui.renderPlatformWindowsDefault();
     }
     ```

3. **面板窗口标志**（可选）
   - 面板默认已经支持多视口
   - 如果需要为特定面板添加菜单栏，可以在`AbstractPanel.getWindowFlags()`中返回：
     ```java
     return ImGuiWindowFlags.ViewportMenuBar;  // 允许创建独立视口并显示菜单栏
     ```

### 注意事项

1. **OpenGL上下文**
   - 多视口需要每个窗口有独立的OpenGL上下文
   - 需要确保Minecraft的渲染系统不会干扰

2. **输入处理**
   - 多视口模式下，输入事件会自动分发到正确的窗口
   - 需要测试键盘和鼠标输入是否正常工作

3. **性能考虑**
   - 多个窗口会增加渲染开销
   - 需要监控帧率影响

4. **兼容性**
   - 某些系统可能不支持多视口
   - 需要添加回退机制

## ⚠️ 重要：多视口功能暂时禁用

**当前状态：多视口功能已在代码中禁用**

**原因：**
在Minecraft环境中测试发现，多视口功能存在严重问题：
1. **UI闪烁**：当面板被拖出窗口时，UI会疯狂闪烁
2. **鼠标输入失效**：主窗口无法接收鼠标操作
3. **OpenGL上下文冲突**：Minecraft完全控制OpenGL上下文，多视口需要切换上下文，导致冲突

**技术原因分析：**
- Minecraft使用自己的OpenGL上下文管理系统
- 多视口功能需要为每个视口创建独立的OpenGL上下文
- `ImGui.renderPlatformWindowsDefault()` 会切换OpenGL上下文，与Minecraft的渲染系统冲突
- 输入事件被Minecraft的输入系统拦截，导致多视口窗口无法接收输入

## 使用方法（如果将来重新启用）

如果将来解决了OpenGL上下文冲突问题，可以重新启用多视口：

1. **启用多视口**：在`ImGuiRenderer.java`中取消注释`ViewportsEnable`标志
2. **拖拽面板到窗口外**：将任何可拖动的面板拖出Minecraft主窗口边界
3. **自动创建独立窗口**：面板会自动创建为独立的操作系统窗口
4. **多屏支持**：可以将面板窗口移动到其他显示器上

**注意事项：**
- 某些操作系统（如Linux X11/Wayland）可能对多视口支持有限
- 如果遇到问题，可以通过修改代码移除`ViewportsEnable`标志来禁用多视口

## 替代方案

由于多视口在Minecraft环境中不稳定，可以考虑以下替代方案：

1. **使用Minecraft的窗口管理**：依赖Minecraft的窗口系统，不创建独立窗口
2. **使用外部工具**：通过屏幕录制或远程桌面等方式实现多屏使用
3. **等待更好的解决方案**：等待ImGUI或Minecraft的更新，可能在未来版本中解决兼容性问题
