# 逐块动画检查与修复（2026-10-12）

## 检查结论

逐块动画保持每个方块独立的序列开始时间、局部轴心、变换与随机种子，整体动画仍使用共享变换。本轮检查发现并修正以下问题：

1. 动画时长占满片段或叠加延迟时，旧的备用时间分配会截短后排动画，拆除甚至可能提前到延迟之前开始。新的 PerBlockAnimationTiming 按延迟后的剩余长度限制单块时长，再分配剩余时间给序列；没有剩余序列时间时，各块同时完成完整动作。引擎、可见性与声音共用这一时钟。
2. 拆除可见性按结束前缀扫描，会漏掉首批退出过程，且动画中的方块未及时从真实世界落地集合移出。现按开始前缀处理，开始时移出世界集合，结束时移出动画集合。
3. 旧交接窗口提前强制缩放和不透明，并同时绘制真实网格。现取消交接覆盖，按抑制切换重建网格后独占绘制；客户端真实方块尚未到达时保留静态动画模型。
4. 逐块动画仍通过实体着色器渲染，存在世界光照差异。现使用地形着色器及显示位置的光照/颜色，每块单独构建局部渲染视图；移动块间不进行邻接面剔除，避免飞开后缺面。整体动画仍保留容器内邻接面剔除。
5. 非零起点的一次性特效先被时间窗口过滤，导致门控无法观察跨越，帧跳也可能漏发。现先记录进度再判断跨越；连续特效仍受窗口限制，回退后可重新跨越触发。完成帧补采样，延迟阶段不提前发射。
6. 动画窗口坍缩的 EXIT 分支原本会在完成后标记可见，现按拆除语义隐藏。

## 游戏内复验

- 普通容器、拆除容器各测试飞入/飞出、缩放、淡入/淡出及瞬时动画，观察首批和末批方块。
- 保持片段长度不变，修改动画时长；测试时长等于片段长度，及动画时长加延迟超过片段长度。
- 序列使用线性、随机、分层等已有预设；动画中的各块分别移动，无整体共享轴心。
- 设置非零特效起点，正常播放观察一次性烟尘；暂停、继续、倒回重播检查重复发射。
- 白天/夜晚、石头/草/树叶/玻璃检查光照及透明纹理；慢速观察落位是否重叠。
- 逐块与整体模式来回切换，检查设置保留及整体模式的已验收行为。
- 大选区逐块播放需观察帧率：每块交接仍需要区块网格更新，按区块段合并请求，但本轮未做游戏内性能基准。

## 验证范围

纯逻辑测试检查时间窗口、所有逐块动画类型的采样和可见性端点、随机变换确定性、声音对齐、特效跨帧门控，以及整体模式回归。编译或单元测试不能代替游戏内 GPU 画面、真实粒子和帧率验收。仅编译与测试，未打包 JAR。

最终验证：编译与逐块、整体动画相关回归命令通过，覆盖最后补充的短片段边界测试。本轮此前全量回归 660 项中 657 项通过，仍为演员系统已有的三项失败。未打包 JAR。
