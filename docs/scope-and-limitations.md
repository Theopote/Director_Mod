# Director 范围与限制

## 定位

Director 是 **单机 / 本地集成服务器** 上的影视制作工具，面向 Machinima、过场动画与离线视频导出。

## 不支持多人协作

本模组 **不提供** 客户端–服务器自定义同步：

- 无 Fabric Networking / Payload / Codec 实现
- 时间线、容器、演员、编辑器状态 **不会** 同步到其他玩家客户端
- 历史上曾存在的 `DirectorNetwork` 仅为未使用的 `Identifier` 占位，已移除

在专用多人服务器上安装 Director 以进行共享剪辑 **不在支持范围内**。

## 推荐运行方式

| 场景 | 说明 |
|------|------|
| 单人游戏 | ✅ 主要目标环境 |
| 集成服务器（单人世界） | ✅ 编辑器与游戏逻辑同进程，数据落盘到本地存档 |
| 局域网仅本地编辑 | ⚠️ 其他玩家看不到 Director 编辑状态 |
| 专用多人服务器 | ❌ 不支持 |

## 与「同步」相关的现有代码

代码中出现的 “sync” 多指 **模块内部状态对齐**（例如时间线与容器名称、摄像机采样与 `CameraRuntime`、可见性服务与方块显示），**不是** 玩家之间的网络复制。

若未来需要真正的多人协作，需要单独设计网络协议与权威状态模型；当前架构未预留该路径。
