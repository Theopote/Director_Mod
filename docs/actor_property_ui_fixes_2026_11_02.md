# 演员属性面板修复

## 数据与撤销

- UV 草稿按模型和方块分别保存；六面分别编辑，修改贴图不再统一各面 UV。只有显式点击“将此 UV 应用到全部面”才会统一。支持取消，外部模型替换后重新读取；提交检查 UV 有限数值，撤销拒绝覆盖被替换的模型。
- 风格改为分离草稿和显式应用，一次应用对应一次撤销。自定义骨架/模型绑定使用检查后的命令，播放、拖动和未完成姿态草稿时禁止操作；换骨架清除不匹配的外观绑定，撤销恢复原绑定。保留现有动画引用以便修复，不擅自删除。
- 骨骼动画片段使用兼容动作目录，显示名称、骨架与引用 ID。新增或更换绑定检查存在性、布局及来源，旧缺失引用保留并可修复；撤销可恢复旧引用。
- 语义动作和局部姿态创建均移入统一创建服务，保留用户配置，并有暂停、锁定、能力与语义动作重叠检查；使用一个撤销命令。

## 当前帧与关键帧

- 整体数值编辑在线性端点片段上保留起止键并写当前帧，提交后的当前采样值与输入一致。撤销恢复原端点模式。SMOOTH 中途编辑不静默转键，明确要求先处理曲线。
- 属性面板增加骨骼关键帧与 Root 关键帧检查视图。单键显示原始值、时间和通道；骨骼键支持数值、时间及插值编辑。多键不把不同部位局部值隐式合并。Root 单键支持所选通道值，删除所选通道保留同一时刻的其他通道，时间调整仍使用既有时间线拖动。
- 替换旧 EntityClipKeyframePropertyAdapter 的临时数组写入和直接改源对象逻辑，复用受检查的整体键服务。
- 距离驱动键的时间线投影和点击定位复用动画源时钟反解；普通动画保留原有快速投影。定位选择距当前播放头最近的有效周期，距离时钟的键拖动重定时仍禁用。

## 检查上下文与只读

- 骨骼/Root 关键帧焦点优先显示键属性，提供返回所属片段；Actor 轨道可解析到演员详情。没有非选择工具覆盖时，演员选择也能显示演员详情。
- 世界点击演员使用“整体选择”意图，清除部位和关键帧焦点；选择部位仍保留明确动画引用。演员详情增加播放头整体变换入口。
- 通用片段检查器在不可编辑时使用分离快照展示禁用控件，并说明只读原因。Route 和道具事件在会话不可写时列出现有配置。
- 收起时间线骨骼区不再全局取消共享数值/Gizmo 草稿；属性面板隐藏不再取消仍由时间线使用的演员草稿。真正改变演员、引用或工程时继续使用上下文失效保护。
- 整体注视面板可直接选择目标演员，不再先切换到缺少 UUID 的实体模式再报错。

## 动画事件

- 独立 Animation 片段增加事件列表、归一化触发位置、片段/动画源时钟、道具动作、槽位、道具及投掷参数编辑。
- 新增、修改和删除通过事件列表命令提交；原参数深拷贝，提交检查参数与源数据。保留并显示已有附加参数；未接入运行时的旧动作不会被自动替换。
- 当前入口针对独立 Animation 片段；不向 Spawn 派生引用新增未持久化的事件入口。

## 验证与边界

正式回归覆盖 UV 草稿/逐面保护、风格及绑定撤销、无效引用拒绝、只读快照不改源数据、当前采样值、平滑曲线保护、单键通道隔离、距离定位、事件深拷贝和参数校验、动作创建撤销。

客户端实机仍需检查：窗口停靠与收起、窄面板和长名称、多个 UV 节点同时输入、Gizmo 与数值草稿切换、多选键焦点、沿路径的循环定位及事件触发。自动测试不能代替这些 UI 验收。

本批没有对所有演员面板做统一视觉重排或全量翻译迁移；路径工具/路线参数/路径库仍分工存在。它们属于后续界面整理，不能将本批描述为所有 UI 设计问题均已解决。
