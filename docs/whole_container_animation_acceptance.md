# 整体动画最终验收

本轮开发范围：通用容器整体出现、拆除容器整体退出，以及对应的属性编辑、项目保存、复制、撤销重做和播放特效。开发收尾后进行游戏内最终验收；以下项目尚未代替人工勾选。

## 功能入口

1. 将通用容器或拆除容器拖到对应时间线轨道。
2. 选中片段，在「动画设置」中将动画范围切换为「整体动画」。
3. 选择动画预设，或编辑基础类型和参数。
4. 在独立的「特效」面板选择整体特效预设，正常播放观察效果。

| 层级 | 已实现内容 |
| --- | --- |
| 基础类型 | 瞬间、平移、缩放、旋转、组合、淡入淡出；出现和拆除分别提供对应方向 |
| 组合通道 | 平移、旋转、缩放、透明度分别开关；关闭通道保留参数 |
| 轴心 | 中心、底部中心、自定义相对中心偏移 |
| 时间 | 起始延迟、动画时长、缓动；有效窗口受片段边界限制 |
| 路径 | 直线、弧线；弧线高度支持正负值 |
| 运动修饰 | 无、回弹、弹跳；强度、次数和阻尼，弹跳另有高度 |
| 动画预设 | 生长、上方/下方/侧面飞行、旋转、旋转生长、旋转飞行、淡入淡出、柔和生长、回弹生长、弹跳落位、弧线飞行 |
| 特效预设 | 无特效、轻柔尘土、落地烟尘、多圈衰减冲击波、碎屑烟尘 |
| 音效 | 整体仅生成一次自动音效，安排在真实方块接管/消失之前 |

## 最终人工验收清单

建议准备一个长方体组合和一个不规则组合，分别建立通用、拆除片段。暂时只放一个片段，验证后再检查多个容器同时播放。

- [ ] **基础方向**：逐一播放六种基础类型。出现完成后方块停在原位置；拆除结束后方块消失。动画中各方块之间的相对位置保持不变。
- [ ] **组合通道**：同时开启四个通道，再逐个关闭。关闭的通道停止参与动画，参数仍保留；重新开启恢复效果。透明度变化不跟随回弹闪烁。
- [ ] **旋转与轴心**：设置 720° 旋转，测试中心、底部和自定义轴心。整体围绕同一轴心旋转，未拆成逐块旋转。
- [ ] **时长与延迟**：时长从 2 秒改为 1 秒，应完整播放并加快。增加延迟时，通用容器等待期间保持隐藏，拆除容器保持完整。动画超过片段长度时仍能在片段结束完成接管。
- [ ] **弧线路径**：选择弧线飞入/飞出；高度分别设为正值、负值、0。路径向上、向下、恢复直线，起点和目标不变。组合中关闭平移后不再走弧线。
- [ ] **回弹与弹跳**：测试对应预设和组合动画。修改强度、次数、高度、阻尼后效果改变；缩短动画时长后节奏相应加快，结束时不残留位移或缩放。
- [ ] **特效**：依次选择无特效、轻柔尘土、落地烟尘、冲击波、碎屑烟尘。出现完成/拆除开始触发一次，连续播放不刷屏；无特效不发射。
- [ ] **碎屑烟尘**：使用石头、木材等不同材质的组合，碎屑应使用来源方块纹理，带重力并碰撞地面；将粒子浓度从 0 调至 5，扩散范围从 0 调至 5，观察数量与范围变化。碎屑比例 0 为烟尘，1 为碎屑，不支持破坏粒子的方块回退为烟尘。默认比例 0.8，单次最多 256 个粒子。
- [ ] **世界渲染一致性**：分别在白天、夜晚及火把附近测试石头、草、树叶、交叉植物、玻璃组合；动画接近落位时，核对亮度、颜色、内部面和透明纹理。慢速播放与反复拖动，检查落位和离场交接是否有黑面、闪烁或短暂缺失。旋转期间面亮度应连续变化。
- [ ] **多圈波纹**：默认 3 圈按约 0.25 秒间隔出现，后续圈逐渐变弱，每圈自身淡出。圈数 1 和 6 均可用；衰减 0 后各圈强度相同，衰减 1 只保留首圈。多圈合计最多 256 个粒子。
- [ ] **播放边界**：在起点点击播放、暂停再继续、循环播放、从片段结束倒回重播。零时刻特效不遗漏，同一轮不重复触发。拖动播放头、倒回或切换项目会清理旧冲击波。
- [ ] **参数编辑**：修改通道、轴心、路径、运动修饰、特效、圈数和衰减，逐步撤销与重做；拖动参数的一次操作对应一个撤销步骤。
- [ ] **预设配合**：切换动画预设会保留时长、延迟和特效；重置动画参数会恢复直线路径和无运动修饰，并保留整体特效。
- [ ] **项目恢复**：保存并重新打开组合动画项目，核对自定义轴心、弧线、运动修饰、特效、圈数和衰减。复制片段后改动副本，不影响原片段。
- [ ] **逐块兼容**：切回逐块动画，原有排序、动画及逐块特效仍可用。再切回整体，之前的整体参数仍保留。
- [ ] **多容器**：多个容器同时播放，轨道隐藏或锁定后不再触发该轨道特效，其他轨道正常播放。

## 粒子与渲染的实际边界

- 方块几何动画使用时间线时间，可确定性地拖动、回退和重播。
- 灰尘与冲击波使用游戏粒子时间。时间线暂停后，已触发的粒子继续消散；游戏暂停时冻结。粒子不随时间线倒放。
- 冲击波按世界底部范围发射，自动限制粒子数量；同时保留的冲击波最多 8 组。
- 整体模型现使用原版世界方块模型渲染，按容器快照进行邻接面剔除和环境遮蔽，按显示位置取世界光照及群系颜色；面亮度随旋转方向变化。裁剪材质保留透明纹理，避免重复应用实体面光照。
- 真实方块可接管时停止覆盖层绘制，取消原有落位时两套模型重叠的策略；原版世界网格与动画覆盖层分别处理渲染拦截。
- 以上渲染修改已通过编译和位置/亮度采样测试，游戏内画面仍需按清单验证；区块异步重建、透明层排序、第三方光影和特殊方块实体不由纯逻辑测试保证。

## 自动验证

仅编译和测试，不执行 JAR 打包：

~~~powershell
.\gradlew.bat compileJava --offline
.\gradlew.bat test --tests '*WholeContainer*' --tests '*WholeMotionCurves*' --tests '*AlphaVertexConsumerTest' --offline
.\gradlew.bat test --offline
~~~

整体动画测试涵盖采样、共享轴心、通道组合、时长编辑、出现/拆除接管、音效时机、弧线、多圈波纹、粒子预算、项目 DTO 保存、复制和撤销重做。自动测试未验证游戏内的实际渲染画面。

最终验证结果：编译通过，整体动画相关 109 项测试全部通过；全量 643 项测试中 640 项通过，3 项失败（既有演员系统失败，列表见下）。

全量测试仍有三项已知演员系统失败，与本轮整体动画开发分开记录：

## 2026-10-12：运动、碎屑与渲染改进

回弹使用阻尼弹簧的单位阶跃响应：
1 - exp(-d*t) * (cos(w*t) + d/w * sin(w*t))，其中 w=2π*次数，t 为有效动画窗口的归一化进度。最后 15% 用五次平滑曲线收敛到精确目标，起步和最终落位速度均为零。阻尼越大，残余振动越小。公式参考 [MIT 阻尼振子课程](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/unit-ii-second-order-constant-coefficient-linear-equations/damped-harmonic-oscillators/)。

弹跳前 40% 按平方曲线加速到首次落位，后 60% 分配给抛物线弹跳。相邻跳跃时间按恢复系数 r=exp(-阻尼/10) 缩短，高度按 r² 衰减，最后一次落位平滑收尾。弹跳高度可独立设置，因此属于可控的动画曲线，并非完整刚体模拟。出现和拆除使用同一归一化曲线的正反方向，修改时长改变速度而不裁掉前半段。

建议先使用“回弹生长”或“弹跳落位”预设：时长 1.5–2 秒、强度 1、次数 2–3、阻尼 6；更稳重可把阻尼提高到 8–10。碎屑烟尘先用浓度 2.5、扩散 1.2、碎屑比例 0.8，再按结构大小调整。特效仍在出现完成或拆除开始触发，音效时机保持在真实方块接管前。
