# 演员时间线通道交互设计

## 目标

演员是一条主轨道及一个生命周期片段。展开的整体变换、骨骼和行为行是通道视图，不创建额外演员、主轨道或生命周期片段。行选择、关键帧选择和演员选择相互关联，但必须是不同状态。

## 现有代码与缺口

- ActorRootTimelineRows 绘制三条整体行；点击调用 ActorSelectionHub.selectActor，尚无整体通道选择状态，也不按行切换 Gizmo。
- 整体关键帧使用 EntityClipKeyframe 的完整 TRS，三行重复绘制同一关键帧；当前删除/移动实际影响所有通道。独立按钮不能直接调用现有完整 TRS 插入后宣称独立打帧。
- ActorBoneTimelineRows 已调用 ActorSelectionHub.selectBone，联动姿态工具。ActorAnimationAuthoringService 已有独立 TRANSLATION、ROTATION、SCALE 通道，可复用。
- 路径区间已支持 Spawn 缩放关键帧及缩放 Gizmo，路径位置/朝向仍受保护。旧 Transform 片段覆盖路径的冲突需要显式处理。

## 行与场景反馈

| 行 | 左键选择后的反馈 | 默认打帧内容 |
| --- | --- | --- |
| 整体位置 | 演员整体选中，三轴移动箭头 | 世界位置 XYZ |
| 整体旋转 | 演员整体选中，水平绿色 Y 环 | 整体朝向；工具只修改 yaw |
| 整体缩放 | 整体缩放手柄，遵循等比锁定 | 比例 XYZ |
| 骨骼汇总行 | 对应骨骼高亮，显示其允许的姿态工具 | 当前选中的骨骼通道 |
| 骨骼下的位置/旋转/缩放 | 对应部位高亮，工具和属性切换到本地通道 | 该骨骼该通道 |

主轨道被选中只切换演员；具体通道被选中才明确切换工具。整行有选中底色；按钮点击必须优先命中，不能同时触发拖片段、框选或播放头跳转。选行不修改当前时间，不自动创建关键帧。点击已有关键帧可定位时间并选择对应通道。

骨骼 Root 是模型局部根，整体位置是世界变换。UI 将前者命名为“模型根（局部）”，用缩进及说明区分；避免两个 Root 操作含义混淆。没有可编辑骨骼的演员不显示虚构的 Body/Head/四肢。

## 行末关键帧按钮

在名称栏右侧保留固定按钮槽（建议 20–24 像素），不随时间线水平滚动。名称截断且有提示，命中区域与时间轴严格分离。

- 空心菱形：当前时间没有本通道关键帧；点击记录当前采样值。
- 实心菱形：当前时间已有本通道关键帧；点击更新其值，不默认删除。删除通过右键菜单或选中关键帧后 Delete，避免误删。
- 按钮提示显示通道、场景时间、写入目标、可用性原因。骨骼通道还标明动画资源时间。
- 初次打帧记录当前值；用户随后移动播放头调整同一通道，已有动画通道可自动写入当前时刻。自动打帧状态必须明确显示，避免无意把基础参数修改理解为动画。
- 播放、拖动播放头、锁定/静音、未绑定有效片段、只读动画资源时禁止写入，仍可选择和查看。
- 路径控制位置/朝向时两行提示“由路径控制”，不伪装成可编辑坐标；缩放独立可用。路径进度/方向偏移是后续专门通道，不能混进世界坐标。

## 整体数据模型

整体关键帧必须能够标识位置、旋转、缩放通道。可以沿用同时间键的数据容器并加入通道掩码，但采样、命中、删除、剪贴板和时间调整都必须按通道处理。

- 旧项目没有掩码：按完整 TRS 解释，保持原动画。
- 新位置帧只参与位置插值；旋转和缩放各自寻找最近关键帧，不能被位置帧隐式插入同值帧。
- 同时刻多个通道可共用容器；删除缩放帧仅去掉缩放标记，其他通道继续存在。
- 拖动单通道帧到其他时间时必须允许拆分容器；目标同通道已有帧时拒绝或显式确认替换，不静默合并覆盖。
- 路径上的缩放帧不携带路径世界位置；关掉路径后仍恢复原本基础位置。
- 骨骼动画继续使用现有独立通道，避免把本地骨骼值混入世界 TRS。

## 统一选择状态

新增明确通道目标：演员 ID、拥有者轨道、目标片段/资源、整体或骨骼目标、通道类型。由统一选择入口广播给工具、属性面板和时间线；任何一处选择都更新同一状态。

切换演员、通道、工具、播放头或项目时取消未提交手势，再更新目标。删除目标、锁定轨道及撤销重做后重新校验状态，不能继续编辑旧对象。选择通道不应清除同演员的有效写入目标片段。

## 推荐实现顺序

1. 整体通道独立数据与采样，补齐旧格式兼容和持久化。
2. 统一通道选择；三条整体行高亮并切换对应 Gizmo，属性面板聚焦目标。
3. 名称栏关键帧按钮；复用独立通道编辑事务，明确自动打帧状态。
4. 骨骼汇总行可展开三个受能力约束的子通道，接入现有骨骼写帧服务。
5. 按通道完善时间轴帧选择、删除、拖动、复制/粘贴；锁定、路径保护和资源冲突统一反馈。

不要在独立数据完成之前把三个整体按钮都接到完整 TRS 写帧；可以先交付选行切换工具，但不得宣称独立通道已完成。

## 验收

- 整体三行分别触发移动箭头、水平环、缩放手柄；选择不改变时间或新增片段。
- 位置在 0/4 秒打帧，缩放在 0/2 秒打帧：2 秒缩放帧不能改变位置插值，位置帧也不能截断缩放插值。
- 删除或移动缩放帧，位置和旋转帧不受影响；同刻其他通道保留。
- 路径移动同时缩放，位置始终沿路径；取消路径后基础位置未被路径坐标污染。
- 点击骨骼行，高亮正确部位，父子本地变换正确；能力不足的通道不出现可写按钮。
- 撤销只回退该次写帧或手势；重做不新增轨道、演员或生命周期片段。
- 旧工程、保存重载、剪贴板、缩放时间线、垂直滚动、收起展开均正确。
