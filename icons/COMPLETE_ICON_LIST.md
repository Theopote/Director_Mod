## 🎯 IcoMoon 导入步骤

### 1. 访问 IcoMoon
打开: https://icomoon.io/app/

### 2. 导入 SVG 文件
1. 点击 "Import Icons"
2. 选择 `E:\ChronoBlocks\chronoblocks\icons\` 目录下的所有 `.svg` 文件
3. 或者拖拽整个 icons 文件夹到 IcoMoon

### 3. 选择图标
- 点击 "Select All" 选择所有图标
- 或者单独选择需要的图标

### 4. 生成字体
1. 点击底部 "Generate Font" 按钮
2. 检查预览，确保所有图标正常显示
3. 可以重新排列图标顺序
4. 可以修改图标名称

### 5. 配置选项（重要）
1. 点击右上角齿轮图标⚙
2. 设置 Font Name: `icomoon`
3. 设置 Class Prefix: `icon-`
4. 勾选 "Use class selector" 和 "Encode & Embed Font in CSS"
5. 字符集从 `0xE900` 开始（Private Use Area）

### 6. 下载字体包
1. 点击 "Download" 下载 ZIP 包
2. 解压后获取：
   - `fonts/icomoon.ttf` ← 字体文件
   - `style.css` ← Unicode 映射表
   - `selection.json` ← 项目文件（可重新编辑）

### 7. 替换项目文件
复制 `icomoon.ttf` 到：
```
src/main/resources/assets/chronoblocks/fonts/icomoon.ttf
```

### 8. 更新 Icons.java
根据新的 `style.css` 更新 Unicode 码位映射

## ⚠️ 重要注意事项

### ✅ 确保图标符合规范

所有图标已按以下规范创建：

1. **纯黑色** (#000000) - IcoMoon 要求
2. **单色设计** - 无渐变、无多色
3. **24x24 画布** - 统一尺寸
4. **简洁路径** - 避免复杂效果
5. **清晰识别** - 2px 描边宽度

### ❌ 避免的问题

- ❌ 彩色图标（会显示为问号或方框）
- ❌ 渐变填充（不支持）
- ❌ 多层复杂效果（简化为单色）
- ❌ 文字/字体元素（转为路径）
- ❌ 外部样式（内联到SVG）
