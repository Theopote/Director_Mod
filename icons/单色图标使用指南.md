```ini
[Font Settings]
Font Name = icomoon
Class Prefix = icon-
Version = 1.0

[CSS Options]
✅ Use class selector
✅ Encode & Embed Font in CSS
✅ Use i tag

[Other Options]
Start from: E900
Metrics: Use font metrics
Ligatures: (optional)
```

## 📥 下载后的操作

### 1. 解压文件
```
icomoon.zip
├── fonts/
│   └── icomoon.ttf ← 复制此文件
├── style.css ← 查看此文件获取映射
└── selection.json ← 保存此文件
```

### 2. 替换项目字体
```powershell
# 复制命令（PowerShell）
Copy-Item "下载路径\fonts\icomoon.ttf" `
         "E:\Director\director\src\main\resources\assets\director\fonts\icomoon.ttf"
```

### 3. 查看映射并更新代码

打开 `style.css` 查找所有 `.icon-` 开头的类：

```css
.icon-add:before { content: "\e900"; }
.icon-play:before { content: "\e901"; }
...
```

在 `Icons.java` 中更新：

```java
public static final String ADD = "\uE900";
public static final String PLAY = "\uE901";
...
```
